# v2 Upgrade Needs

The codebase is already in a solid v1 shape with App Router, server actions, SEO metadata, PWA support, and a custom image pipeline. The v2 goal is not a rewrite, but a few focused upgrades that improve scale and user experience.

## My Needs

- Reduce data loading overhead on the home page.
- Move product loading toward server-side pagination or cursor-based loading so watchlists stay fast as they grow.
- Improve chart loading so opening multiple charts does not create repeated slow requests.
- Consider caching, batching, or a dedicated endpoint for price history data.

## Current Gaps

- `page.tsx` fetches all tracked products for the signed-in user.
- `ProductGrid.tsx` paginates only after all products are already loaded.
- `PriceChart.tsx` loads history on demand for each card.
- `actions.ts` serves price history through a server action, which is simple but may not scale well.

## v2 Direction

- Keep the upgrade focused and practical.
- Improve performance before adding new features.
- Preserve the current UI and behavior where possible.
- Make the data flow easier to scale later.
